# 优课学习助手：Windows 本机更新助手

适用于开发者模式加载的独立解压目录。浏览器自身不能覆盖该目录，因此通过 Native Messaging 与本机助手协作；不修改浏览器安全策略，也不接管商店安装的扩展。

## 首次安装

1. 先手动将插件更新到 **1.2.0 或更高版本**，重新加载扩展。
2. 在插件设置页“版本与更新”中展开“首次安装本机助手”，复制扩展 ID。
3. 解压 `uooc-updater-windows.zip`，运行 `UoocUpdater.exe`。
4. 粘贴扩展 ID，选择浏览器当前实际加载、直接包含 manifest.json 的独立插件目录，选择 Edge 或 Chrome，点击“关联并安装”。ID 与目录不匹配时会拒绝关联。
5. 回到插件设置，点击“授权并连接本机助手”。显示已连接后可手动更新；开启自动检查与自动安装即可自动更新。

本助手不负责首次加载浏览器扩展。若本机安全或组织策略阻止运行，请按本机管理要求处理，不要关闭安全防护。

## 更新过程

- 来源固定为 https://github.com/qiuxingya/uooc-helper 的最新非草稿、非预发布 Release。
- 只选择 `uooc-helper-版本.zip` 附件，不使用 GitHub 自动生成的源码包或 Release 正文中的链接。
- 验证 GitHub 提供的 SHA-256、ZIP 路径与文件类型、MV3 名称和版本、当前扩展 ID 与目录。
- 先暂存下载，再检查优课与学习通页面是否全部关闭，随后原路径替换并由插件调用 runtime.reload。
- 新版后台启动后确认更新，才清理旧文件备份。未在约90秒内确认时恢复旧文件；浏览器异常时可能仍需手动重新加载扩展或重开浏览器。
- 新增权限、访问范围或身份变化时拒绝自动覆盖，需人工查看发布说明并升级。

2.0.0 新增学习通站点范围，从 1.2.0 升级时需要手动替换原插件目录并重新加载，保留原加载路径。助手本身无需因这次扩展版本编号变化而重装。
- 不降级；校验失败、网络失败和目录不适合更新时保留当前版本。不会读取浏览器密码、Cookie 或插件 API Key。

覆盖期间保留原目录路径及未被新版替换的额外文件。需要独立、可写的插件安装目录；不要关联包含 `.git`、开发工作目录或浏览器 User Data 的路径。

## 本机存储与卸载

安装文件位于当前用户的 `%LOCALAPPDATA%\UoocHelperUpdater`，仅在当前用户的 Edge／Chrome NativeMessagingHosts 注册表项注册，不需要管理员权限，不设置开机服务。只允许安装时明确关联的扩展 ID 调用。

插件设置中关闭“自动安装”会停止后续自动覆盖。再次运行安装器并点击“解除关联”，可移除本助手自己的浏览器注册项，不删除插件和学习数据；关闭后可手动删除上述助手目录。

## 构建与发布

源码为 `UoocUpdater.cs`，使用 Windows .NET Framework 和系统自带编译器。可在允许执行脚本的 PowerShell 环境运行 `./build.ps1`，无需额外安装 Python 或 Node。

助手自身不从 Release 自动替换 EXE。若将来助手协议或能力发生变化，应单独发布新版助手供用户审阅后安装。

## 1.1.0 静态清单

日常检查读取固定的最新正式版 update.json 附件，不使用 GitHub REST API。首次从旧助手升级时，请下载新版独立助手 ZIP，替换旧文件，运行 UoocUpdater.exe 并重新关联原扩展 ID 与安装路径。
