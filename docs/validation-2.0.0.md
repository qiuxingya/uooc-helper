# 2.0.0 验证记录

记录日期：2026-11-03。测试使用桌面版 Edge；模拟接口与真实账号结果分别记录。

## 已确认的真实页面结果

- 已核对学习通课程中心的学生课程卡片、课程＋班级标识、章节多视频 iframe、任务完成标记、学习记录及综合成绩表结构。
- 已确认当前账号可见 11 门课程；当前列表分页容器为空。
- 已确认学习记录与综合成绩页可使用精简课程地址读取，不需要持久化临时签名参数。
- 修复 `/base` 自动添加时间参数导致扫描无法开始的问题。
- 修复首页默认打开学校“学习空间”，导致最后账号复核超时的问题。仅扫描任务通过网站唯一可见的“课程”菜单进入列表，普通页面不自动导航。
- 修复后，使用者在已登录账号上明确确认：刷新成功，能够看到课程成绩。

## 仍待确认与限制

- 学习通真实连播启动/暂停、真实登录检测及真实账号跨浏览器重启的结果尚待反馈。模拟会话集成证明浏览器持久机制，不证明学校或服务器永远认可会话。
- 依使用者确认，尚无可编辑真实样例的学习通章节测验暂缓适配，自动答题和自动提交保持关闭。优课已有答题流程继续保留。
- 跨域受限 iframe、学校验证、考试、图片题与特殊课程入口需要人工处理；不自动解决验证码或身份验证。
- 未做长期服务器会话有效期测量；服务器失效、学校单点登录和浏览器退出清理策略仍可能要求重新登录。
