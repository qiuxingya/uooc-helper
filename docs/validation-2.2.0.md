# 2.2.0 验证记录

本轮适配用户提供的 POLYMAS AI教学中心智能体课程：学习资源视频、成绩总览与可选登录保持。知到共享课与可编辑习题未接入。模拟回归通过不代表真实网站完整验收通过。

## 真实页面检查（2026-11-16）

- 经授权使用 Edge 原有登录会话查看学习资源目录、视频详情、课程主页和任务列表。仅检查必要页面结构和接口字段，不发布个人课程信息、账号标识或真实账户截图。
- 资源树使用 tree/treeitem、data-key、file-name、file-tag、node-action-rate-text 等标记。普通 checked 也出现在未完成资源上，仅绿色 success 或有效 100% 进度作为完成标记。
- 视频预览位于 `https://polymas.com/resource/online/preview/`，课程容器位于 `https://hike-teaching-center.polymas.com`。课程名称从 drawer-title 或 course-title 读取，不把视频标题当课程名。
- 通过网站原有登录会话核验个人资料、学期、班级、成绩及成绩配置的接口响应结构，只输出字段名和必要权限布尔值，不导出 Cookie、令牌或成绩数值。公开前端脚本补充确认学生身份及课程列表请求参数；未将研究中的通用旧列表接口用于正式实现。
- 实际课程配置为 `isViewScore:false`、`isArchive:false`。正式实现先检查公布权限；未公布时不请求分数，显示“未公布”，不把网站内部可返回的分数当已公布成绩。
- 网站成绩接口没有可靠的学习资源完成度字段，成绩页显示“暂无数据”及来源说明；不从成绩推断视频＋测验完成度。面板已有网页资源进度保持独立。
- 页面出现过域名解析失败、连接关闭、超时和混合内容警告。真实视频正常播放、连续切换和统计尚未通过真实插件验收。成绩管理路由也出现空白加载，不作为学生成绩入口。
- 本轮未在真实会话修改 Cookie，未测试关闭重开浏览器后的登录保持，未执行真实交卷、验证码、付费模型请求或浏览器安全设置修改。最后一次浏览器连接检查未发现可用 Edge 窗口，因此完整扩展成绩刷新与真实登录保持仍待用户重载后验收。

## 模拟验证

完整回归 **343 项通过，0 失败、0 跳过**，耗时约 145 秒。命令：`node --test --test-concurrency=2 tests/*.test.cjs`。环境为 Node.js 24、隔离无头 Edge；输出保留于已忽略的 `.test-artifacts/regression-2.2.0-grades-login.tap`。未访问真实付费模型、未交卷。

### 视频与页面边界

- 目录与详情入口、课程名、资源完成标记、跨域正常结束续播、倍速即时修改、PDF 排除与学习统计。
- 打开页面不自动播放；用户启动后才计时。用户暂停、定时停止、启动承诺迟到、旧 iframe 移除和新 iframe 握手不能恢复已停止任务。
- 自动播放被拒时提示人工点击，不把未播放视频当完成；拒绝伪造消息、来源窗口和域名，媒体桥接不提供密钥接口。
- 桌面和 390px 面板、更多区域、边界和收起操作。

### 成绩与账号

- 当前学生身份校验；按课程、班级和学期去重隔离；分页列表与当前已选智能体课程过滤；固定只读接口及参数白名单。
- 未公布时不读取成绩；真实 0 分、缺失字段、普通当前总分与已归档总评分别处理；未知资源进度不算已完成。
- 单课刷新、集中重试失败课程、保留旧快照、顺序读取、最终账号核对、取消和迟到响应、30 天缓存清理。
- 持久化任务在服务休眠重建后继续；Cookie 凭据变化使账号缓存失效；多个班级/学期摘要不擅自选择其中一条。
- 刷新前用户手势授权，拒绝不发扫描请求，重复点击不重复启动；平台切换和账号通知清除旧成绩。

### 登录保持与安全

- 仅显式开启后处理已识别的第一方登录 Cookie；验证当前登录后才将会话 Cookie 延长至 7 天，保留原有安全属性，不改网站原有有效期 Cookie。
- 关闭时仅恢复仍匹配本插件修改记录的 Cookie。退出登录期间发生的迟到写入回滚，不复活已退出的会话。
- 动态授权后绑定 Cookie 事件；三平台统一开关兼容旧版混合配置，新平台默认关闭。
- Cookie 和令牌只在可信后台用于固定官网接口，不返回设置页、课程脚本、日志或导出文件。后台不接受网页指定任意接口或其他标签页。
- 其余现有优课、学习通、设置、密钥、更新和学习记录回归均包含在上述 343 项中。
