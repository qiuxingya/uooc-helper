## 过程中发现并修正的问题

迁移旧测试时发现项目外页面样本和辅助文件依赖，现已改为仓库内模拟样本及辅助文件。检查页面改为保留播放状态后，旧测试仍断言状态被诊断文字覆盖，已改为校验诊断数据与播放状态同时正确。上述问题已修正并重跑，不计为跳过。

最终增加旧播放器事件隔离后，99项播放与恢复定向回归中98项通过，发现学习通已结束视频不再属于候选播放器，正常结束被误拦。现已改为校验可见性与真实运行所有权，学习通5项连播测试重新全部通过。原有98项检查没有未处理失败。

## 消息接口

后台错误保留 error 中文说明，新增固定 code 和可选 retryAfterMs（毫秒）。课程脚本按 code 判断可重试错误，不匹配中文句子。推测请求成功时增加 guessed 标记，即使模型自报确定，也标注推测来源。调用者角色、真实发送标签页隔离及密钥访问范围不变。日志和诊断仅增加固定阶段、错误代码及计数。

## 真实页面验收与限制

本版本尚未在用户浏览器重新加载后执行真实课程验收。没有调用真实付费模型，没有自动完成验证码，没有保存或提交真实课程。模拟测试不证明所有课程兼容。学习通未新增可编辑测验答题能力；旧版真实成绩读取的证据不替代本次2.1.0真实验收。

断点与答案仅存在当前页面内存，刷新后清除。推测答案仍可能错误；自动提交默认关闭，但用户既有开关值保留。重发请求可能重复计费，已经发出的请求无法撤销费用。

## 开发与复现

使用Node.js 24、桌面Edge，执行 npm install --ignore-scripts 后执行 npm test。运行目录为仓库根目录，测试输出写入已忽略的 .test-artifacts/。CI使用同一测试入口。安装用户无需Node.js。
