# 2.3.2 验证记录

## 真实页面复现与对照（2026-11-18）

在用户已登录的 Edge、智慧树 `studyvideoh5.zhihuishu.com/stuStudy` 页面操作已安装的 v2.3.1：

- 未启动助手时，网站播放器以原有 1.5× 正常播放。
- 两次点击助手“开始连播 · 2×”后，网站弹出“检测到异常脚本，为保证您的正常学习进度，请您关闭插件后，回到学堂重新进入视频学习页正常学习”，随后返回智慧树首页。
- 该提示出现时旧助手仍显示“正在连续播放，视频结束后切换”，说明异常反馈未被识别。
- 检查网站实际 DOM，`.speedBox .speedTab` 仅提供 `rate=1.0/1.25/1.5`。
- 返回课程，将旧助手选择为 1× 启动，随后改为 1.5×，持续播放超过两分钟，没有再次观察到异常提示。

初步对照仅支持超出网站范围的倍速可能是触发点之一。随后在 1.5× 恢复弹题时仍出现异常脚本提示，说明不能据此认定只限制倍速即可消除拦截；没有修改网站检测。没有修改网站检测、隐藏提示、操作验证码或正式交卷。期间另观察到一次网站 Video.js `tech` 使用警告，关闭普通提示后恢复课程，不改写原生函数或平台安全逻辑。

此为旧版在真实网站上的复现与支持倍速对照，不等于新源码已在用户日常浏览器安装验收。新版本真实重载、完整视频结束后的真实下一节、真实弹题和学习记录入账仍待验收。

## 后续真实弹题检查

当前弹题为单选，网站在选择选项后立即显示“错误/正确答案”等反馈，底部一直只有“关闭”。页面题干位于 `.topic-title` 的末尾直属 span，选中标记为 `.topic-option-item.active`、`.item-topic.active`，反馈位于独立 span 和 `.answer`。旧助手显示“已修改的答案尚未完整”。

为核对选中状态，人工点击一次普通练习选项，网站给出正确答案；此步骤不是插件 AI 成功验收。随后点击旧助手“继续连播 · 1.5×”仍触发异常脚本提示，未观察到完整关闭续播成功，停止真实操作。

本地回归复现同类卡住路径：同一弹窗关闭重开或 Vue 重建选项时，旧断点把新空选项当作用户清空；即时反馈混入题干也可使题目标识变化。新代码隔离弹窗生命周期与输入节点身份，读取独立题干，丢弃旧请求，并保留人工修改保护。

## 修复范围

- 智慧树只调用网站原有倍速按钮，不直接写入播放器 playbackRate/defaultPlaybackRate，最高 1.5×；原 1.75×/2× 设置仅在智慧树本页限制，不自动覆盖共享设置。
- 原三平台的倍速逻辑不变。共享课面板禁用超过 1.5× 的选项，更新中文说明；章节作业流程保留。
- 识别真实可见的异常脚本提示并以 MANUAL 原因停止，取消后续助手操作；隐藏预置提示不误停。提示消失也不自行恢复。
- 找不到唯一的网站倍速入口时明确暂停，不回退到强制设置播放器属性。
- 无新增权限、远程接口、检测绕过或学习进度上报；内置助手仍为 1.2.0。

- 新增即时反馈、关闭重开、选项重建与请求/多选填写期间重开取消的专项回归。断点仅在当前页面内存中，不新增题目、答案持久存储。

## 异常提示即时停止补充

用户再次反馈连播弹题会触发异常脚本提示。未反复在真实账号触发警告。检查发现原先主要依赖播放轮询和操作前检查，在答题请求/关闭等待期间可能延迟停止。新增页面变化观察与异步运行检查：检测到网站可见异常提示即取消当前请求与运行，不隐藏提示、不修改检测结果、不重复点击关闭，提示消失也不自行恢复。

两个新增专项通过，记录 `.test-artifacts/zhs-warning-immediate.tap`：禁用播放轮询后注入警告，仍立即取消模型请求且迟到答案不填写；点击关闭按钮触发警告时只点击一次，不恢复视频、不发模型请求。均为模拟验证，不证明网站允许自动答题。本轮完整回归 **369 通过、0 失败、0 跳过**，记录 `.test-artifacts/regression-2.3.2-warning.tap`；此前367项是上一轮结果，交付以本轮369项为准。
